How to Install in StreamElements

  1. Log in to your StreamElements Dashboard.
  2. Go to Streaming Tools > Overlays and create or edit an overlay.
  3. Add a new widget: Click Add Widget (+) > Static/Custom > Custom Widget.
  4. Click on the newly added widget, and click Open Editor in the settings panel.
  5. Copy and paste the code from each tab above into its respective editor tab (HTML, CSS, JS, Fields) in StreamElements.
  6. Click Done, then click Save in the top right corner of the overlay builder.
